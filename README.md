## 🔧 Features

- Lightweight & fast

## ⚙️ Installation (Termux / Linux)

Follow the steps below to install and run the tool in **Termux** or any Linux terminal.

### 1. Update your packages
```bash
pkg update && pkg upgrade -y
```

### 2. Install required dependencies
```bash
pkg install python git -y
```

### 3. Clone this repository
```bash
git clone https://github.com/salmanahmedakhash/sms-bomber.git
cd sms-bomber
```

### 4. Install Python libraries
```bash
pip install requests
```

---

## ▶️ How to Run

Once everything is installed, simply run:

```bash
python Sbai.py
```

You will be asked to input a mobile number. The script will attempt to send multiple SMS/OTP requests using online services.
